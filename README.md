# ПВХ · прогноз и решения

Прогноз анонимизированного показателя **k** недельного ряда
**«ПВХ SG-5 (Китай) DAP Достык, USD/т»** на следующие **13 недель**.
Источник — официальный файл организаторов конкурса.

## Быстрый запуск

Python 3.12. Поместите предоставленный `.xlsb` в `data/raw/predictors.xlsb`.
Исходные данные и производные таблицы фактических цен не публикуются в Git.
Каждая облачная задача уже изолирована: используйте существующий checkout,
не создавайте Git worktree без отдельного запроса.

```bash
cd /workspace/Roshim_hakaton
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python src/finalize.py --rebuild
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python src/validate_artifacts.py
.venv/bin/streamlit run app.py --server.headless true
```

Время первого расчёта зависит от машины: выполняются 24 исторических блока,
16 кандидатов, затем парные эксперименты с обновлением прогнозов.
Кеш предсказаний привязан к содержимому входного файла и коду; повторный запуск
использует его. `--data /path/to/input.xlsb` меняет путь к файлу.
`--skip-refresh` пропускает дополнительный эксперимент пересчёта; для полного
комплекта и демо запускайте без этого флага.

## Что проверяется

**Фиксированный прогноз.** Весь файл используется как обучающая история для
финальной модели. Конкурсный тест из него не вырезается. Для исторических
проверок используются 24 неперекрывающихся блока по 13 недель. В каждом блоке
модели получают только историю до его начала, включая внешние индикаторы.

**Исследовательский последовательный выбор.** В каждом блоке семейство модели выбирается по
среднему sMAPE последних 8 полностью завершённых блоков. Первые 4 блока —
разогрев, следующие 20 — проверка этого правила. Кандидат первоначально выбран
по последним 8 завершённым блокам. Перед сдачей проверены два осторожных ансамбля;
они не прошли все ограничения без ухудшения, поэтому исходный кандидат сохранён.
Финальный прогноз обучается на всей истории, без переключения в конкурсном периоде.
Это исторический backtest; новый независимый конкурсный результат пока неизвестен.

**Кандидаты.** Naive, seasonal naive, Holt и затухающий Holt на всей истории и
коротких окнах, затухающий локальный тренд, прямой Ridge по горизонтам,
CatBoost с квадратичной и абсолютной функцией потерь, варианты с внешними
индикаторами и без них, простой ансамбль. Подробности — `src/models.py`.
Признаки и их отбор пересчитываются внутри каждого обучающего префикса.
Цель не включается повторно в набор внешних рядов.

**Рост ошибки.** `balanced_horizon_metrics.csv` сравнивает горизонты 1–13 на
одних и тех же полных исторических блоках. `horizon_metrics.csv` дополнительно
показывает все доступные факты с числом наблюдений для каждого горизонта.

**Пересчёт.** Для одной и той же фактической даты сравниваются прогноз при t
и прогноз после поступления t+1. Отдельно исследуется еженедельный пересчёт
до одношагового прогноза. Семейство модели в пределах исходного блока сохраняется.
Этот сценарий получает новые данные и НЕ подменяет фиксированный конкурсный прогноз.

**Интервалы.** Эмпирический 90%-й ранг ошибок предыдущих завершённых блоков
по горизонту, нормированный на известную в момент прогноза волатильность.
Минимум 9 калибровочных наблюдений. Покрытие и ширина измеряются на следующих
блоках. Независимость ошибок и стабильность режима не гарантированы.

**Финальная стратегия (активная версия v2).** Фильтр исторической ошибки и максимум
одна активная неделя на 13-недельный блок. Порог сигнала — максимум из 0,5%
последней цены и половины медианной прошлой ошибки недельного изменения
для данного горизонта. Из сигналов выбирается максимальное отношение
прогнозного изменения к порогу; будущий P&L не используется.
На 20 разработческих блоках: P&L +0,11450, просадка 0,01527; после условных
затрат 0,1% на оборот +0,08012. Пять прибыльных и два убыточных блока,
12 активных недель. Доля лучшего в положительных результатах 36,8%; после
его исключения стресс-P&L остаётся +0,02905. Это небольшая исследованная
выборка, не независимый тест и не гарантия будущей прибыли.
В итоговом CSV одна короткая позиция (-1) на первой неделе, затем 0.
Нулевой резервный вариант сохранён отдельно. Правила и сравнение:
`config/finalization.json`, `artifacts/final_strategy_comparison.csv`.

**Финальная сборка.** `python src/finalize.py --rebuild` воспроизводит исследование
и замораживает итоговую конфигурацию; `python src/finalize.py` использует готовые
исторические прогнозы. Затем `python src/validate_artifacts.py` проверяет результат,
а `python src/build_delivery.py` формирует `deliverables/Roshim_submission.zip`,
двухстраничный PDF-отчёт и пять слайдов PPTX. Только `src/pipeline.py` повторяет
исследование и возвращает его стратегию, поэтому для сдачи используйте finalize.

## Качество данных и защита от утечек

- Даты, значения и атрибуты читаются непосредственно из XLSB.
- 552 исходные записи цели превращаются в 551 наблюдаемую календарную неделю:
  в одной неделе два релиза, используется последний. Ещё 13 недель пропущены.
- Праздничные публикации относятся к пятнице своей недели. Для признаков
  используется только заполнение из прошлого; факты и обучающие ответы Ridge/
  CatBoost не заполняются искусственными значениями.
- Недоступные более 45 дней котировки исключаются из признаков.
- Контрактные сценарии исключены: встречаются конфликтующие котировки с
  одинаковыми датой и атрибутами и неизвестными сроками публикации.
- Межрыночные признаки — изменения логарифмов и расхождения динамики,
  не разности абсолютных анонимизированных цен. Уровень собственной цели допустим.
- Ранжирование внешних рядов выполняется только на известной обучающей истории.
- Пропуски не участвуют в метриках. P&L считается только там, где обе
  соседние фактические недельные цены наблюдаемы; прибыль за разрывы не заявляется.
- Дата записи принимается за дату доступности: точное время релиза не предоставлено.

## Календарь сдачи

Последняя цель — 03.07.2026. Следующие 13 пятниц: **10.07–02.10.2026**.
Официальные шаблоны задают `week_start` как **пятницы 10.07–02.10.2026**.
Сдаём `forecast.csv` с колонками `week_start;horizon;forecast;forecast_lower;forecast_upper`
и `strategy.csv` с колонками `week_start;position`. Разделитель `;`, UTF-8 с BOM.
Внутренние диагностические CSV остаются с запятыми.
Прогноз и все 13 позиций фиксируются один раз, без еженедельного пересчёта.
Дедлайн — **29 октября, 21:00 по Москве**. Промежуточной проверки нет;
организаторы оценивают последние полученные файлы и не передают скрипты скоринга.
Полные уточнения: [docs/RULES_2026-10-28.md](docs/RULES_2026-10-28.md).
Шкала точности теперь основана на отрыве `sMAPE(naive) − sMAPE(модели)` в п.п.;
пересекающиеся диапазоны не преобразуем в точные баллы самостоятельно.
Для перевыгрузки готовых прогнозов без обучения: `.venv/bin/python src/submission.py`.
Другие ряды заканчиваются 06.07.2026; для согласованности модели используют
признаки по последнюю пятницу цели.

Индекс k не переводится в рубли без коэффициентов и объёмов. Связь рядов не
называется причинностью. Улучшение модели, интервалов или P&L утверждается
только в пределах фактически выполненных проверок.
