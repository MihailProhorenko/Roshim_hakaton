# Прогноз цены ПВХ — Росхим

Первая воспроизводимая версия решения: показатель **k** недельного ряда
«ПВХ SG-5 (Китай) DAP Достык, USD/т», прогноз на 13 будущих недель.


## Запуск

Python 3.12. Поместите официальный `.xlsb` в `data/raw/predictors.xlsb`.
Данные не включены в Git, поскольку разрешение на их публикацию не установлено.

```bash
cd /workspace/Roshim_hakaton
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 .venv/bin/python src/pipeline.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/streamlit run app.py --server.headless true
```

Аргумент `--data /path/to/file.xlsb` задаёт другой путь к официальному файлу.
Артефакты пересоздаются в `artifacts/`; запуск не меняет исходный Excel.
В Git сохранены прогноз, стратегия и сводные результаты. История фактических
цен, подробные проверочные прогнозы с фактами и каталог исходных рядов
остаются локальными и восстанавливаются командой запуска после добавления датасета.

## Методика

- Полная предоставленная история — обучающая; конкурсный период внутри неё не отрезается.
- Исторические проверки: 8 неперекрывающихся блоков по 13 недель.
- Первые 6 блоков выбирают модель по среднему sMAPE. Последние 2 — внешняя оценка;
  нельзя подбирать модель по этим двум блокам и продолжать называть их независимыми.
- После выбора модель заново обучается на всей предоставленной истории.
- Модели: naive, seasonal naive, Holt, damped Holt, прямой Ridge по горизонтам,
  Ridge с внешними рядами и простой ансамбль.
- Доступность признаков определяется датой наблюдения. Будущие значения сырья не используются.
- Внешние признаки выбираются заново внутри каждого обучающего окна.
- Межрыночные признаки — изменения логарифмов, без сравнения абсолютных уровней k.
- Контрактные котировки исключены: у них неоднозначные даты и конфликтующие записи.
- Праздничные наблюдения цели относятся к пятнице своей недели; при нескольких
  публикациях за неделю используется последняя. Пропущенные недели сохраняются
  как пропуски: для авторегрессионных признаков допускается только ffill,
  отсутствующие факты не участвуют в метриках и обучающих ответах Ridge.
- В P&L пропущены переходы, для которых отсутствует фактическая цена с одной
  из сторон; никакая прибыль за такие периоды не утверждается.
- 90%-е эмпирические границы строятся по ошибкам первых 6 блоков отдельно по
  горизонту; это предварительные интервалы, а не гарантия покрытия.
- Правило стратегии заранее фиксировано: знак изменения прогнозной цены;
  при изменении не больше 0.5% последней фактической цены позиция равна нулю.
  Первая позиция сравнивает прогноз с последним фактом, остальные — соседние прогнозы.

## Выходные файлы

- `submission.csv`: week_start,horizon,forecast, ровно 13 строк.
- `strategy.csv`: week_start,position, ровно 13 строк.
- `forecast_details.csv`: дата наблюдения, интервалы и позиции.
- `validation_folds.csv`, `validation_predictions.csv`: все исторические прогнозы и метрики.
- `model_selection.csv`: выбор модели только по первым 6 блокам.
- `outer_evaluation.csv`: факты, прогнозы и покрытие интервалов на последних 2 блоках.
- `leaderboard.csv`: описательное сравнение на всех 8 блоках, НЕ критерий выбора модели.
- `strategy_validation.csv`: чувствительность P&L к порогу на всех 8 блоках, НЕ выбор порога.
- `series_catalog.csv`, `run_metadata.json`: аудит и контрольная сумма входного файла.

## Календарь и ограничения

Последняя цена цели датирована 03.07.2026. Следующие 13 пятниц — 10.07–02.10.2026.
В CSV `week_start` — понедельник соответствующей недели: 06.07–28.09.2026.
До получения официального шаблона это явная рабочая конвенция.
В других рядах есть данные по 06.07.2026; первая версия использует признаки только
по последнюю пятницу цели, консервативно исключая более поздние наблюдения.

Денежная интерпретация k неизвестна: P&L показывается в условных единицах,
а не в рублях. Выводы о причинности и гарантированной точности не делаются.
Официальные скореры и CSV-шаблоны пока не предоставлены.
